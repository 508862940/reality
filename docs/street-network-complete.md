## 📋 设计原则

1. **连通性优先** - 确保所有节点可达
2. **地铁站连接** - 每条街道连接地铁出口
3. **环形+放射** - 符合城市结构
4. **NPC路线考虑** - 为NPC作息设计留空间

## ⭕ 第一环主干道（R1）

### 1. 天枢环路（Ring Road 1）
- **类型**：环形主干道
- **连接**：环绕第一环，连接四个核心节点
  - 警局（北）↔ 医疗区（东）↔ 学院区（南）↔ 天穹苑（西）↔ 回到警局
- **长度**：约2.5公里（环形）
- **宽度**：35米
- **功能**：第一环的快速环线
- **地铁出口**：
  - 中央广场北站（警局）
  - 医疗中心站（医疗区）
  - 学院站（学院区）
  - 天穹苑站（天穹苑）

### 2. 宪章大道（北向放射）
- **连接**：中央广场 → 警局（R1）→ 二环警局（R2）→ 三环警局（R3）
- **长度**：2.8公里
- **宽度**：40米
- **所属区域**：天衡区
- **地铁**：北线沿线
- **特点**：秩序轴线，监控密集

### 3. 生命环路（东向放射）
- **连接**：
  - 中央广场 → 医疗区（R1）→ 电视台（R2）→ 博物馆（R2）→ 幻梦乐园（R3）→ **白桦社区（R3）** → 图书馆（R3）
- **长度**：4.2公里
- **宽度**：35米
- **所属区域**：启明区
- **地铁**：东线沿线
- **特点**：最长的主干道，启明区主动脉
- **重要**：延伸到白桦社区（居住区），连接大量NPC住所

### 4. 启蒙路（南向放射）
- **连接**：中央广场 → 学院区（R1）→ 公园（R2）→ 晨曦里（R3）→ 静海台（R4）
- **长度**：3.5公里
- **宽度**：30米
- **所属区域**：静安区
- **地铁**：南线沿线
- **特点**：学术氛围，林荫大道

### 5. 观景大道（西向放射）
- **连接**：中央广场 → 天穹苑（R1）→ 万象商业区（R2）→ 工业区（R3）→ 梧桐里（R3）
- **长度**：3.8公里
- **宽度**：40米
- **所属区域**：开拓区
- **地铁**：西线沿线
- **特点**：从奢华到贫困的渐变

## ⭕ 第二环主干道（R2）

### 6. 二环环路（Ring Road 2）
- **类型**：环形次干道
- **连接**：环绕第二环，连接9个节点
  - 二环警局 → 电视台 → 博物馆 → 商业区（南）→ 公园 → 晨曦里 → 教堂 → 星语庭 → 万象商业区 → 回到二环警局
- **长度**：约5公里
- **宽度**：30米
- **功能**：第二环的环形快速路

### 7. 星辰大道（媒体中心主路）
- **连接**：电视台 ↔ 博物馆
- **长度**：800米
- **宽度**：25米
- **特点**：媒体区域，广告牌密集

### 8. 霓虹天街（商业中心）
- **连接**：万象商业区 ↔ 回声商业街（南）
- **长度**：1.2公里
- **宽度**：40米（步行街）
- **特点**：繁华商业，夜晚霓虹灯

### 9. 林荫路（公园周边）
- **连接**：静谧之园 ↔ 晨曦里 ↔ 教堂
- **长度**：1.5公里
- **宽度**：25米
- **特点**：绿化带，约会圣地

## ⭕ 第三环主干道（R3）

### 10. 三环环路（Ring Road 3）
- **类型**：环形次干道
- **连接**：环绕第三环，连接7个节点
  - 三环警局 → 幻梦乐园 → 白桦社区 → 图书馆 → 晨曦里（南）→ 梧桐里 → 工业区 → 回到三环警局
- **长度**：约7公里
- **宽度**：28米
- **功能**：第三环主环线

### 11. 狂欢街（娱乐区）
- **连接**：幻梦乐园主入口 ↔ 周边商业
- **长度**：600米
- **宽度**：35米
- **特点**：娱乐设施、游乐场

### 12. 书海路（文化区）
- **连接**：图书馆 ↔ 白桦社区
- **长度**：900米
- **宽度**：20米
- **特点**：安静、书店、咖啡厅

### 13. 劳动路（招工区）
- **连接**：梧桐里 ↔ 工业区
- **长度**：1.5公里
- **宽度**：30米
- **特点**：工人聚集、招工广场、蓝领氛围

### 14. 创造者大街（工业主路）
- **连接**：工业区站 ↔ 齿轮工业区核心 ↔ 废弃工厂
- **长度**：2公里
- **宽度**：35米
- **特点**：货运卡车、厂房、烟囱

### 15. **白桦大道（重要！居住区主路）**
- **连接**：白桦社区 ↔ 生命环路 ↔ 郊区公交站
- **长度**：1.8公里
- **宽度**：25米
- **特点**：
  - **大量NPC住所**
  - 公寓楼密集
  - 日常生活设施（超市、学校、诊所）
  - **郊区公交始发站**（通往远风镇）

## ⭕ 第四环道路（R4）

### 16. 边缘公路（Frontier Highway）
- **连接**：精工业区 → 边界森林入口 → 远风镇 → 静海台
- **长度**：约10公里（不完全环形）
- **宽度**：20米（部分路段仅15米）
- **类型**：郊区公路
- **路况**：部分破损，远风镇段土路
- **特点**：
  - 无地铁
  - 路灯稀少
  - 危险区域

### 17. 郊区土路（远风镇内部）
- **连接**：远风镇各区域
- **长度**：零散分布
- **宽度**：8-12米
- **类型**：土路/碎石路
- **特点**：法外之地、无监控

### 18. 海景大道（别墅区）
- **连接**：静海台别墅群 ↔ 海边
- **长度**：3公里
- **宽度**：30米
- **特点**：高档、私密、风景优美

## 🚶 NPC典型移动路线（基于街道网络）

### User的日常路线
**天穹苑（住所）→ 学院区（上课）**
- 步行：天穹苑小区 → 观景大道 → 天穹苑站（地铁）→ 学院站 → 启蒙路 → 真理学院
- 时长：步行5分钟 + 地铁8分钟 + 步行3分钟 = 16分钟

### Zero的秘密路线
**工业区（关押地）→ 医疗区（帮助User）**
- 路线：
  1. 废弃工厂 → 步行创造者大街 → 工业区站
  2. 工业区站 → 工业快线 → 白桦站
  3. 白桦站 → 东线 → 医疗中心站
  4. 医疗中心站C出口 → 康复花园密道
- 时长：步行10分钟 + 地铁35分钟 + 步行5分钟 = 50分钟

### 社交AI的随机路线（白桦社区居民）
**白桦社区（住所）→ 万象商业区（购物）**
- 路线1（地铁）：
  - 白桦大道 → 白桦站 → 东线 → 博物馆站 → 换乘一号环线 → 万象城站
- 路线2（步行+地铁）：
  - 白桦大道 → 三环环路 → 梧桐里站 → 西线 → 万象城站
- **Utility AI决策**：
  - 如果赶时间 → 路线1（快但贵）
  - 如果省钱 → 路线2（慢但便宜）
  - 如果心情好天气好 → 部分步行欣赏风景

## 🎲 动态事件生成点

### 高频事件街道
- **霓虹天街**（商业区）：购物、约会、偶遇
- **林荫路**（公园区）：散步、跑步、浪漫事件
- **白桦大道**（居住区）：邻里互动、日常琐事
- **劳动路**（工业区）：工人纠纷、招工、帮派

### 低频事件街道
- **宪章大道**（政务区）：执法、抗议、调查
- **边缘公路**（四环）：危险事件、野生AI、走私

### 时间影响
- **早高峰（7-9点）**：白桦大道 → 工业区站（工人通勤）
- **晚高峰（17-19点）**：反向
- **深夜（22-3点）**：远风镇周边（黑市、非法交易）
