- **文件**：`js/core/npc-ai-system.js` (Lines 490-648)
- **扩展行为权重**：
  - **保护User**：
    - 历史问候+0.5（熟悉=更愿保护）
    - 收到礼物+1.5（投资=责任感）
    - 对话总次数+0.8（深度了解=更在意安全）
  - **远离User**：
    - 历史问候-0.8（越熟悉=越难远离）
    - 收到礼物-1.2（收礼多=亏欠感）
    - 被拒绝+3.5（累积挫败=想逃避！）
    - 对话总次数-0.5（深度关系=难以割舍）
  - **热情打招呼**：
    - 历史问候+2.5（越熟悉=越自然热情！核心）
    - 收到礼物+1.8（收礼=亲密度，更热情）
    - 被拒绝-3.0（拒绝多=不敢热情）
    - 对话总次数+1.5（聊得多=舒适感）
  - **冷淡回应**：
    - 历史问候-2.0（越熟悉=越不会冷淡）
    - 收到礼物-1.5（收礼多=不好意思冷淡）
    - 被拒绝+4.0（拒绝多=防御性冷淡！）
    - 对话总次数-1.0（聊得多=关系深，不冷淡）
  - **狼魂爆发**：
    - 历史问候+0.3（熟悉=更在意User伤害）
    - 收到礼物+1.0（收礼多=更珍视关系=愤怒）
    - 被拒绝+1.5（累积负面情绪=更易失控）
    - 对话总次数+0.5（深度关系=更强保护欲）

## 🐛 常见问题排查

### 问题1：状态向量维度错误
**症状**：控制台报错 `vector1.length !== vector2.length`

**解决**：
```javascript
// 检查状态向量长度
window.StateVectorBuilder.build(window.zero, {}).length
// 应该返回：26

// 检查决策矩阵权重数组长度
Object.values(window.zero.utilityAI.decisionMatrix).forEach(arr => {
    console.log(arr.length);
});
// 每个数组都应该是：26
```

### 问题2：记忆未正确注入
**症状**：老朋友状态的 `eventCounts` 仍然为空

**解决**：
```javascript
// 手动触发记忆注入
window.sceneManager.handleSpecialEffect('injectFriendMemory');

// 验证
window.zero.memory.eventCounts
// 应该显示：{ greeted: 50, gift: 5, dialogue: 100, rejected: 0 }
```

### 问题3：AI决策结果不显示
**症状**：点击"▶️ 触发AI决策"后界面无反应

**解决**：
1. 检查控制台是否有错误
2. 确认 `window.zero` 和 `window.zero.utilityAI` 存在
3. 手动触发决策：
```javascript
const decision = window.zero.utilityAI.decide({
    player: { health: 100, trauma: 0, mood: 100 },
    distance: 0.2,
    hasEnemy: false,
    world: { weather: 'sunny', time: 'day' }
});
console.log(decision);
```
