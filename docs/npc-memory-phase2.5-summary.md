## 📋 完成内容

### 1. ✅ 修复归一化公式（边际递减效应）
**文件**: `js/core/npc-ai-system.js` (Lines 177-185)

**修复前问题**：
```javascript
// 旧公式：Math.min(count / 10, 1)
问候10次 → 10/10 = 1.0（满分）
问候50次 → 50/10 = 5 → min(5, 1) = 1.0（满分）
问候100次 → 100/10 = 10 → min(10, 1) = 1.0（满分）
// ❌ 无法区分深浅关系！
```

**修复后**：
```javascript
// 新公式：Math.min(Math.sqrt(count) / divisor, 1)
totalGreetings: Math.min(Math.sqrt(this.getEventCount('greeted')) / 10, 1)
totalGifts: Math.min(Math.sqrt(this.getEventCount('gift')) / 3, 1)
totalRejections: Math.min(Math.sqrt(this.getEventCount('rejected')) / 2, 1)
totalDialogues: Math.min(Math.sqrt(this.getEventCount('dialogue')) / 15, 1)

// ✅ 边际递减效应：
问候10次 → √10/10 = 0.316（初识）
问候50次 → √50/10 = 0.707（老友）
问候100次 → √100/10 = 1.0（挚友）
```

totalHelped: Math.min(Math.sqrt(this.getEventCount('helped')) / 8, 1)       // 被帮助次数
