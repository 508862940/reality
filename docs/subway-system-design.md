# 🚇 新京市地铁系统设计方案 v2.0

> **混合式设计：环形 + 放射 + 快线**
> 创建时间：2025-10-05

---

## 📋 设计理念

### 核心原则
1. **中心放射** = 权力从天枢区向外扩散
2. **环线系统** = 各环内部快速连接，不经中心
3. **启明区特别发达** = B组织控制区域，地铁网络最密集
4. **隐藏通道** = 某些地铁站有通往"里层世界"的秘密入口

### 设计目标
- ✅ 真实感强（参考北京、东京、伦敦）
- ✅ 效率高（环线可以不经中心直达）
- ✅ 分流作用（减少中央车站拥堵）
- ✅ 玩法丰富（"倒3趟车"的任务增加趣味性）

## 🎯 NPC典型路线

### Zero的秘密路线
**目的**：从工业区关押地 → 医疗中心帮助User

**路线**：
1. 齿轮工业区（废弃工厂） → 步行 → 工业区站
2. 工业区站 → **工业快线** → 白桦站（避开中心监控）
3. 白桦站 → **东线** → 医疗中心站
4. 医疗中心站 → 步行 → 康复花园密道

**总时长**：约45分钟（游戏时间）
**优势**：不经过中央车站，避免A组织监控

---

### 观察者的通勤路线
**目的**：静海台别墅 → 医疗中心工作

**路线1（日常）**：
1. 静海台（四环） → 步行/私家车 → 白桦站
2. 白桦站 → **东线** → 医疗中心站

**路线2（紧急）**：
1. 静海台 → 郊区公交 → 白桦站
2. 白桦站 → **东线** → 医疗中心站

---

## 🔐 隐藏要素与秘密

### 通往里层世界的入口

| 地铁站 | 入口位置 | 通往何处 |
|-------|---------|---------|
| **二环警局站** | 废弃月台 | 地下监狱、A组织秘密设施 |
| **电视台站** | B3层设备间 | B组织宣传控制中心 |
| **公园南门站** | 深夜关闭的通道 | 里层世界-实验场 |
| **工业区站** | 废弃轨道 | 废弃工厂深层、Zero关押地 |

### Zero的秘密据点
- **工业快线某节废弃车厢** - Zero留下的工具、暗号、补给

### 时间事件
- **深夜1点后** - 北线有警用专列运送"特殊人员"
- **凌晨3点** - 某些站点会短暂关闭进行"维护"（实则组织活动）
- **暴雨天** - 工业快线会因积水停运，迫使NPC改变路线

## 🎮 游戏玩法设计

### 地铁任务类型
1. **倒车任务** - "在30分钟内倒3趟车到达目的地"（熟悉线路）
2. **跟踪任务** - "跟踪可疑人物，不要被发现"（利用换乘甩开）
3. **拾取任务** - "在某个站台拾取Zero留下的暗号"
4. **时间挑战** - "深夜1点乘坐北线，目击警用专列"

### 随机事件
- 地铁延误（迫使改变路线）
- 遇到熟人（触发对话）
- 车厢内的对话（收集情报）
- 突发检查（警察检查证件）
