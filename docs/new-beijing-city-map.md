## 🌍 核心概念

### 城市定位
- **名称**：新京市 (Xinjing City)
- **整体氛围**："祥和的现代都市造景" - 表面完美、干净、秩序井然，实则充满监视与控制的巨大实验场
- **地理结构**：被海洋包围的同心圆城市
- **环层**：中心 + 四环
- **风格渐变**：核心冰冷精英化 → 外围生活功能化 → 最外层失控蛮荒

### 设计哲学
- **楚门世界式**：完美的虚假世界
- **西部世界式**：隐藏的控制系统
- **由内向外的失控**：越接近边缘，真相越多

## 🎨 五大区域划分

### 1. 天枢区 (Tianshu Sector) - 中央
**象征**：北斗第一星，天空枢纽
**气质**：神圣、绝对中心、不可侵犯
**范围**：中央广场及周边核心地带
**暗喻**：整个"虚假世界"的运转核心

### 2. 天衡区 (Tianheng Sector) - 北部
**象征**：天平、法度、代天执法
**气质**：威严、秩序、不容置疑
**范围**：贯穿一至三环的北部扇形区域
**核心地标**：三级警局系统（一环警局→二环分局→三环派出所）
**功能**：权力与秩序的执行者

### 3. 启明区 (Qiming Sector) - 东部
**象征**：知识之光、科技启蒙
**气质**：文化、科技、信息控制
**范围**：贯穿一至三环的东部扇形区域
**核心地标**：
- 医疗中心（康复身体）
- 媒体中心（塑造思想）
- 博物馆（记录"历史"）
- 图书馆（知识殿堂）
- 幻梦乐园（娱乐控制）

**暗线功能**：B组织的思想控制网络前线

### 4. 静安区 (Jing'an Sector) - 南部
**象征**：虚假的宁静、被安排的安逸
**气质**：生活、休憩、理想化日常
**范围**：贯穿一至四环的南部扇形区域
**核心地标**：
- 真理学院（教育体系）
- 静谧之园（中央公园）
- 晨曦里/白桦社区（居住区）
- 静海台（别墅区）
- 圣光教堂（精神控制）

**暗喻**："被安排好的美好生活"

### 5. 开拓区 (Kaito Sector) - 西部
**象征**：繁华→蛮荒的过渡
**气质**：经济心脏、生产基地、边疆探索
**范围**：贯穿一至四环的西部扇形区域
**核心地标**：
- 天穹苑（顶级豪宅）
- 万象商业区（经济中心）
- 齿轮工业区（生产心脏）
- 梧桐里招工区（蓝领聚集地）
- 边界森林（未知危险）
- 远风镇（法外之地）

**双重含义**：经济开拓 + 玩家探索边界

## 🚇 交通系统

### 地铁网络

**覆盖范围**：中心 + 第一环（全覆盖） + 第二环（全覆盖） + 第三环（部分覆盖）

| 线路 | 站点列表 | 备注 |
|------|---------|------|
| **中央线** | 中央车站 | 地铁枢纽 |
| **北线（秩序轴）** | 中央广场北站 → 二环警局站 → 工业区北站 | 天衡区主线 |
| **东线（启明线）** | 医疗中心站 → 电视台站 → 博物馆站 → 幻梦乐园站 → 白桦站 → 图书馆站 | 启明区环线 |
| **南线（静安线）** | 学院站 → 公园南门站 | 静安区主线 |
| **西线（开拓线）** | 天穹苑站 → 万象城站 → 工业区站 → 梧桐里站 | 开拓区主线 |

### 公交系统

**第三环 ↔ 第四环专线**

| 线路 | 起点 | 终点 | 频率 | 特点 |
|------|------|------|------|------|
| **郊区专线** | 白桦站（三环） | 远风镇（四环） | 30分钟一班 | **唯一通往郊外的公交** |

### 交通特点

1. **地铁密集区**：一环、二环全覆盖，快速便捷
2. **地铁衰减区**：三环部分覆盖，开始出现盲区
3. **公交唯一区**：四环只能靠公交接驳
4. **步行危险区**：边界森林、精工业区需步行探索
