## 1. 游戏设计哲学

### 核心理念
- **不是**: 传统视觉小说剧情向游戏
- **而是**: 高自由度沉浸式情感探索
- **重点**: 所有复杂引擎服务于情感模拟和沉浸式体验

### 参考游戏
| 游戏 | 借鉴要素 |
|------|----------|
| Degrees of Lewdity | 世界探索、NPC分层系统 |
| 博德之门3 | 后台暗投骰子（不显示给玩家） |
| 星露谷/荒野大镖客 | NPC独立作息系统 |
| 塞尔达传说 | 世界快照存储系统 |
| 西部世界 | 线索式探索、体验式叙事、剧情暗线 |
| 模拟人生 | 感知机决策矩阵 |

## 2. NPC情感神经网络架构

### 2.1 系统架构图
```
输入层（环境感知）
├── 时间（早/晚）
├── 天气（晴/雨）
├── 地点（公园/实验室）
├── User行为（接近/远离/对话）
├── 自身状态（疲劳/药物/狼魂）
└── 组织控制度
        ↓
隐藏层（情感处理）
├── 好感权重
├── 信任权重
├── 依赖权重
├── 愧疚权重
└── 冲突权重
        ↓
输出层（行为决策）
├── 对话选择
├── 行动路线
├── 情感表达
└── 逃避/接近
```

### 2.2 核心特点
- 玩家**永远看不到具体数值**
- 没有"好感度+10"的提示
- 只有行为和对话的细微变化
- 通过NPC反应推测关系状态

## 3. 多维情感模型

### 3.1 情感维度定义

| 维度 | 含义 | 增加方式 | 影响范围 |
|------|------|----------|----------|
| **好感** (Affection) | "我喜欢和你待在一起" | 闲聊、符合喜好的礼物、说笑话 | 日常互动频率 |
| **信赖** (Trust) | "我相信你不会伤害我" | 完成承诺、危险时保护、说真话、保守秘密 | 深层对话解锁 |
| **尊敬** (Respect) | "我钦佩你的能力和品德" | 艰难但正确的决定、展现能力、为弱者挺身而出 | NPC主动求助 |
| **迷恋** (Intrigue) | "你充满未知的魅力" | 出人意料的选择、矛盾的一面、哲学性对话 | 特殊剧情触发 |

### 3.2 实现示例
```javascript
// NPC情感状态
npc.emotions = {
    affection: 0.5,    // 好感：日常互动积累
    trust: 0.3,        // 信赖：承诺与背叛
    respect: 0.4,      // 尊敬：能力与品德
    intrigue: 0.6      // 迷恋：神秘与矛盾
}
```

## 4. 分层记忆系统

### 4.1 记忆层级结构
```
实时事件 → 重要性过滤器 → 短期记忆(24h)
                            ↓
                        周记忆(7天)
                            ↓
                        月记忆(30天)
                            ↓
                        年记忆(365天)
                            ↓
                        十年记忆(3650天)
                            ↓
                    核心永久记忆(∞)
```

### 4.2 记忆筛选机制

#### 筛选规则
- **99%的日常会被遗忘**
- **1%的关键时刻改变人生轨迹**

#### 淘汰机制
| 时间节点 | 筛选规则 | 保留数量 |
|---------|---------|----------|
| 每天结束 | 筛选今天最重要的事件 | 1-2条进入周记忆 |
| 每周结束 | 筛选本周最重要的事件 | 2-3条进入月记忆 |
| 每月结束 | 筛选本月最重要的事件 | 1-2条进入年记忆 |
| 每年结束 | 筛选本年最重要的事件 | 1-2条进入十年记忆 |
| 特殊事件 | 直接标记为永久记忆 | 不限（初吻、背叛、生死时刻） |

### 4.3 核心记忆类型

| 类型 | 描述 | 影响 | 示例 |
|------|------|------|------|
| **觉醒时刻** | NPC自我意识觉醒 | 永久改变行为模式 | "我是谁？" |
| **初恋/爱情** | 第一次心动 | 影响未来情感倾向 | 与User初次心动 |
| **重大创伤** | 造成心理阴影的事件 | 永久性格改变 | 目睹杀人、被背叛 |
| **身份发现** | 重要身份真相 | 改变世界观 | 发现自己是AI |
| **背叛/牺牲** | 信任崩塌或奉献 | 影响信任基准值 | User的背叛/保护 |

### 4.4 NPC分级记忆配置

```javascript
// 背景NPC（90%）- 极简记忆
backgroundNPC.memories = ["recent_event_1", "recent_event_2"]  // 最多3条

// 功能NPC（8%）- 基础记忆
functionalNPC.memories = {
    week: ["event1", "event2"],
    month: ["important_event"]
}

// 可攻略NPC（2%）- 完整记忆
romanceableNPC.memories = {
    short: [...],       // 短期记忆（24小时）
    week: [...],        // 周记忆
    month: [...],       // 月记忆
    year: [...],        // 年记忆
    decade: [...],      // 十年记忆
    core: [...],        // 永久核心记忆
    ai_context: ""      // AI接口上下文
}
```

## 5. 记忆影响系统

### 5.1 记忆权重修正器

记忆会作为"权重修正器"影响未来的情感计算：

```javascript
// 记忆标签影响权重
memoryModifiers = {
    "user_kept_promise": {trust: 1.2},      // 信任增益+20%
    "user_betrayed": {trust: 0.5},          // 信任增益-50%
    "user_showed_weakness": {respect: 0.8}, // 尊敬增益-20%
    "user_saved_me": {affection: 1.5}       // 好感增益+50%
}
```

### 5.2 十年后的情感印记

十年后只记得"感觉"而非细节：

```javascript
decade_memories = [
    {
        type: "emotional_imprint",
        description: "曾经深深信任过某人",
        impact: { trust_baseline: -0.2 }  // 永久降低基础信任值
    },
    {
        type: "love_memory",
        description: "第一次心动的感觉",
        trigger: "similar_situation",     // 相似场景会触发
        impact: { affection_volatility: 0.3 }  // 更容易心动
    }
]
```

## 6. 心情上下文系统

### 6.1 情绪滤镜机制

同一行为在不同心情下产生完全不同的反馈：

| 玩家行为 | NPC心情高(>80) | NPC心情中(40-80) | NPC心情低(<40) |
|---------|---------------|------------------|----------------|
| 讲笑话 | "哈哈，谢谢你" (+10好感) | "嗯，还行吧" (+2好感) | "我没心情..." (-3好感) |
| 送礼物 | "太贴心了！" (+15好感) | "谢谢" (+5好感) | "现在不是时候" (0好感) |
| 请求帮助 | "当然！" (立即帮助) | "让我想想..." (延迟) | "抱歉，我..." (拒绝) |

### 6.2 实现代码
```javascript
function handlePlayerAction(action, npc) {
    const mood = npc.stats.mood;

    if (action === "tell_joke") {
        if (mood >= 80) {
            npc.emotions.affection += 0.1;
            return "真的笑出来了";
        } else if (mood >= 40) {
            npc.emotions.affection += 0.02;
            return "礼貌性微笑";
        } else {
            npc.emotions.affection -= 0.03;
            return "皱眉";
        }
    }
}
```

## 7. 社交网络影响系统

### 7.1 间接影响传播

公开事件会影响在场的其他NPC：

```javascript
// 事件：在众人面前保护Zero
publicEvent("protect_zero") {
    // 直接影响
    zero.trust += 20;
    zero.respect += 15;

    // 在场者影响
    witnesses.forEach(npc => {
        if (npc.values === "courage") {
            npc.respect += 10;  // 欣赏你的勇气
        }
        if (npc.relation_to_zero === "hostile") {
            npc.affection -= 15;  // 不满你的立场
        }
    });

    // 6小时后传播为流言
    setTimeout(() => {
        gossipTargets.forEach(npc => {
            npc.intrigue += 5;  // 产生好奇
        });
    }, gameHours(6));
}
```

### 7.2 影响传播范围

| 距离 | 影响程度 | 示例 |
|------|---------|------|
| 0（直接） | 100% | Zero本人 |
| 1（在场） | 50% | 目击者 |
| 2（听说） | 20% | 朋友圈 |
| 3（流言） | 5% | 整个区域 |

## 8. 性能评估

### 8.1 数据量估算

| NPC类型 | 数量 | 单个大小 | 总计 |
|---------|------|---------|------|
| 可攻略NPC | 2 | 1.5KB | 3KB |
| 功能NPC | 10 | 0.5KB | 5KB |
| 背景NPC | 50 | 0.1KB | 5KB |
| **总计** | **62** | - | **约13KB** |

### 8.2 优化策略

1. **记忆压缩**
   - 使用ID枚举代替完整字符串
   - 相似记忆合并

2. **懒加载**
   - 只在交互时加载NPC记忆
   - 背景NPC使用简化记忆

3. **自动清理**
   - 定期清理过期短期记忆
   - 根据重要度自动提升/淘汰

## 9. Utility AI决策示例

### 9.1 Zero的决策矩阵
```javascript
const zeroDecision = {
    // 多维度内在状态
    dimensions: {
        affection: 75,      // 对User的情感
        trust: 60,          // 信任度
        wolfControl: 40,    // 狼魂控制度
        medication: 70,     // 药物效力
        guilt: 85,          // 内疚感
        conflict: 90        // 内心冲突
    },

    // 可选行动及效用计算
    actions: [
        {
            id: 'protect_user',
            utility: (d) => d.affection * 0.3 + (100 - d.wolfControl) * 0.2 + d.guilt * 0.1,
            conditions: { wolfControl: {min: 30} }
        },
        {
            id: 'distance_self',
            utility: (d) => d.guilt * 0.4 + d.conflict * 0.3 - d.affection * 0.2,
            conditions: { medication: {min: 50} }
        },
        {
            id: 'wolf_outbreak',
            utility: (d) => (100 - d.wolfControl) * 0.6 + (100 - d.medication) * 0.4,
            conditions: { wolfControl: {max: 20} }
        }
    ]
};
```

## 附录：关键设计决策记录

1. **为什么不显示数值？**
   - 增加沉浸感，玩家通过观察判断
   - 避免数值化降低情感真实性
   - 鼓励玩家真正"理解"NPC

2. **为什么使用分层记忆？**
   - 模拟真实的人类记忆机制
   - 性能优化，避免无限增长
   - 创造"似曾相识"的浪漫效果

3. **为什么要有社交网络影响？**
   - 世界更真实，NPC不是孤岛
   - 增加决策深度，需要权衡
   - 创造意外和涌现式剧情
